# Exports do SageMaker Canvas

Use este diretório para organizar arquivos exportados da interface durante a execução real do Lab.

Antes de versionar qualquer exportação, confirme que o arquivo não contém identificadores de conta, credenciais, dados pessoais ou outras informações sensíveis desnecessárias.

Arquivos temporários grandes ou dispensáveis não precisam ser mantidos no Git; preserve apenas o que sustenta a reprodutibilidade e a análise final.
