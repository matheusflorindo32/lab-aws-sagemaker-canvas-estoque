# Métricas do modelo

Armazene aqui apenas métricas reais obtidas na execução do Amazon SageMaker Canvas.

Não crie valores demonstrativos que possam ser confundidos com resultados experimentais. Registre a data da execução, configuração do modelo e origem de cada métrica.

Consulte `../../docs/06-avaliacao-modelo.md` para critérios de interpretação.
